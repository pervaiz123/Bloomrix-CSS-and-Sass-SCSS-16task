# Bloomrix Responsive Admin Dashboard

A responsive admin dashboard built using HTML, advanced CSS, Sass/SCSS and JavaScript.

## Features

- Responsive admin dashboard layout
- Collapsible mobile sidebar
- Summary cards
- Searchable task table
- Status filtering
- Status and priority badges
- Create-task modal
- Form validation
- Light and dark themes
- CSV task export
- Responsive phone, tablet and desktop layouts
- Accessible labels and focus states
- Reduced-motion support

## Technologies

- HTML5
- CSS3
- Sass/SCSS
- JavaScript
- Vite

## Project Structure

- `abstracts`: Sass variables, functions and mixins
- `base`: CSS reset and global styles
- `layout`: Sidebar, navigation and dashboard layout
- `components`: Buttons, cards, badges, tables and modal
- `pages`: Dashboard-specific styling
- `js`: Dashboard functionality

## SCSS Concepts Used

- Sass variables and maps
- Sass functions
- Reusable mixins
- `@use` and `@forward`
- Shallow nesting
- CSS custom properties
- Responsive media queries
- CSS Grid and Flexbox
- BEM-style component naming
- CSS transitions and keyframes
- Reduced-motion preferences

## Sass and CSS Variables

Sass variables are evaluated during compilation.

CSS custom properties remain in the browser and can change at runtime.

The dashboard uses CSS custom properties for theme switching and Sass variables for reusable design values.
